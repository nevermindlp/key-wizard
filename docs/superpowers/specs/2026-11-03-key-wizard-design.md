# 按键精灵设计

日期：2026-11-03

Windows 桌面小工具。一个窗口里改完配置即可生效，并提供两件事：按当前鼠标位置循环左键点击；录制鼠标移动和点击，再按设定次数重放。其他软件处于前台时，全局快捷键仍然可用。

## 技术选型

- Python 3.11+
- 界面：tkinter（标准库）
- 鼠标与全局热键：pynput
- 配置与录像：JSON

本次用 `python main.py` 启动。打包成 exe、图像识别、键盘录制、脚本编辑器不在范围内。单元测试可在 macOS 上跑；真实鼠标与全局热键以 Windows 为准。

## 状态

程序同时只做一件事，状态为 `idle`、`clicking`、`recording`、`playing`。

下表里的五个动作各对应一个快捷键。键位存在配置里，可以在界面中修改。下表使用默认键名，只为读起来方便；改键之后，同一列的行为跟着新键走。

| 当前状态 | 连点键（默认 F6） | 开始录制键（默认 F8） | 停止录制键（默认 F9） | 回放键（默认 F10） | 急停键（默认 Esc） |
| --- | --- | --- | --- | --- | --- |
| idle | 开始连点 | 开始录制 | 无效 | 有录像则开始回放 | 无效 |
| clicking | 停止连点 | 无效 | 无效 | 无效 | 立即停止 |
| recording | 无效 | 无效 | 停止并保存 | 无效 | 立即停止并保存已录内容 |
| playing | 无效 | 无效 | 无效 | 停止回放 | 立即停止并松开尚未松开的鼠标键 |

窗口上的按钮与对应快捷键做同一件事。关闭窗口时，先停止当前动作再退出。若当时正在录制，与按下停止录制键相同，会先把已录内容写入文件。

## 循环点击

开始时不锁定坐标。每一次点击都使用点击发生那一刻的鼠标位置，因此连点过程中可以挪动鼠标。

- 只发送左键单击（按下后立刻松开）。
- 第一次点击立刻发生，之后每次点击前等待一个间隔。点满 `count` 次后进入 `idle`。
- 间隔模式 `fixed`：每次等待 `interval_ms`。
- 间隔模式 `random`：每次在 `interval_min_ms` 与 `interval_max_ms` 的闭区间内独立抽取一个整数毫秒。
- 数值范围：间隔 10–60000 毫秒；`count` 为 1–100000。随机模式下最小值不得大于最大值。

等待可被停止打断，打断后不再多点一次。

## 录制

录制鼠标移动，以及左键、右键的按下与松开。不记录键盘，不记录滚轮。

- 每 16 毫秒读一次光标坐标。与上一个已记录的移动点相同时，不写入。
- 按下或松开立刻写入，不等待采样周期。
- 每个事件带 `dt_ms`，表示距离上一个已写入事件的毫秒数。第一条事件的 `dt_ms` 为 0。
- 停止录制键或急停键结束时，把事件列表写入 `data/recording.json`。没有任何事件时写入空列表。
- 采样间隔固定为 16 毫秒，不出现在界面上。

事件形状：

```json
{"type": "move", "x": 100, "y": 200, "dt_ms": 16}
{"type": "click", "x": 110, "y": 210, "button": "left", "pressed": true, "dt_ms": 40}
```

`button` 只取 `left` 或 `right`。`pressed` 为 `true` 表示按下，`false` 表示松开。坐标是整数像素。

## 回放

录像为空时，回放键与「开始回放」不启动，状态行显示「没有录像」。

- 按事件顺序：先等待该事件的 `dt_ms`（可被停止打断），再执行。
- `move` 把光标移到 `(x, y)`。
- `click` 在 `(x, y)` 对对应键执行按下或松开。
- 整段录像重复 `replay.repeat` 次，每次从头播放。次数范围 1–10000。
- 中途停止时，若某个键已按下且本次回放还没松开，补一次松开。

## 配置何时生效

配置文件是 `data/config.json`。目录不存在时创建。第一次启动写入下面的默认值。

界面字段在失焦时校验：

- 通过且当前为 `idle`：立刻写入文件。快捷键有变化时，拆掉旧监听并按新键重新监听。
- 通过且正在执行：界面保留新值，但本次动作继续使用开始时的配置快照。动作结束、回到 `idle` 后写入文件并启用新快捷键。
- 失败：该字段恢复为上次有效值，状态行说明原因。

## 修改快捷键

五个快捷键都能改，改完会写入 `data/config.json`，下次启动仍然有效。

窗口最下方有五行，每行是一个动作：循环点击、开始录制、停止录制、回放、紧急停止。行上显示当前按键。点击该行的「设键」后，下一次按下的键替换这一项，状态行显示「已改成某键」。

规则：

- 只接受单个键，不接受组合键。允许的键是 `esc`、`f1`–`f12`、单个小写字母，以及主键盘数字 `0`–`9`。小键盘数字不接受。
- 五个快捷键必须互不相同。新键与另一项重复时，这次修改取消，状态行说明冲突，原键保留。
- 空闲时修改立刻生效：写入配置，拆掉旧的全局监听，按五个新键重新监听。
- 正在连点、录制或回放时可以先把新键填进界面，本次动作仍响应开始时的旧键。回到空闲后写入配置并换成新键。
- 急停键也可以改，但不能留空。改掉之后，新的急停键负责立即停止。

默认配置：

```json
{
  "click": {
    "interval_mode": "fixed",
    "interval_ms": 200,
    "interval_min_ms": 100,
    "interval_max_ms": 300,
    "count": 20
  },
  "replay": {
    "repeat": 1
  },
  "hotkeys": {
    "toggle_click": "f6",
    "start_record": "f8",
    "stop_record": "f9",
    "toggle_replay": "f10",
    "emergency_stop": "esc"
  }
}
```

`interval_mode` 只取 `fixed` 或 `random`。热键字符串的允许范围见「修改快捷键」。

## 界面

窗口标题为「按键精灵」。自上而下四块：

1. 状态行。空闲、连点「已点击 n/count」、录制「已记录事件数与时长」、回放「第 r/repeat 次」。校验错误和「没有录像」也写在这里。执行中显示「修改会在本次结束后生效」。
2. 循环点击。间隔方式二选一。固定模式可编辑固定间隔，随机最小/最大禁用。随机模式相反。另有点击次数，以及「开始连点 / 停止连点」按钮。
3. 录制回放。重复次数、录像摘要（事件数，以及全部 `dt_ms` 相加得到的总时长；没有事件时显示「尚未录制」），按钮为「开始录制」「停止录制」「开始回放 / 停止回放」。
4. 快捷键。五行都可以改：动作名称、当前按键、「设键」按钮。点击「设键」后，下一次按键写入该行。

按钮的可用状态与上表一致。例如录制中只有「停止录制」和窗口关闭可用，其余开始类按钮禁用。急停只有快捷键，没有对应按钮。

界面每 50 毫秒从队列取出引擎进度并刷新。引擎不直接碰控件。

## 模块

```text
main.py                      # 创建配置目录、启动界面
key_wizard/models.py         # 配置、事件、状态的数据结构
key_wizard/config_store.py   # 读写 JSON、校验、默认值
key_wizard/engine.py         # 状态机、工作线程、停止信号
key_wizard/backend.py        # 鼠标与热键接口；pynput 实现
key_wizard/ui.py             # tkinter 窗口
tests/test_config_store.py
tests/test_engine.py
```

`backend.py` 定义可替换接口：取坐标、移动、按下、松开、开始/停止鼠标监听、开始/停止热键监听、当前时间。引擎依赖这个接口。单元测试注入假实现和可控时钟，不移动真实鼠标。

引擎对外方法：

- `start_click(snapshot)`、`stop()`
- `start_record()`、`stop_record()`
- `start_replay(snapshot)`
- `add_progress_listener(callback)`，回调只收到纯数据，由界面线程排队刷新

工作放在一条后台线程。热键回调只负责投递命令，不在监听线程里睡眠或点鼠标。

## 错误处理

- 配置文件损坏或字段非法：忽略该文件，改用默认配置，状态行提示已恢复默认。录像文件损坏则视为没有录像。
- 热键监听启动失败：状态行显示「热键监听失败」，窗口按钮仍可操作。
- 重复热键、空热键、不支持的键名：拒绝本次修改并恢复原值。
- 停止连点或回放时，正在进行的等待立刻结束。

## 测试

单元测试不调用真实鼠标：

- 默认配置可写可读；非法间隔、次数、重复次数、重复热键被拒绝。
- 随机间隔在闭区间内，固定间隔始终等于设定值。用注入的随机函数断言。
- 状态机拒绝上表中的无效开始动作；停止与急停能从任何执行状态回到 `idle`。
- 连点：假时钟下恰好点击 `count` 次，间隔符合模式；等待中停止则不再点击。
- 录制：坐标不变的采样被丢掉；点击立即进入事件列表；`dt_ms` 与注入时钟一致。
- 回放：按 `dt_ms` 顺序产生移动和按下/松开；重复次数正确；中断时补发松开。

Windows 上手工确认：跟随鼠标连点、F6 再按停止、录一段移动加左右键并回放、回放次数、执行中改间隔要到下次才变、Esc 能停、五个热键改掉后仍然生效。
